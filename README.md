# Orbit 产品工作台

桌面端 H5 产品经理工作台原型，包含登录、产品原型文档管理、产品文档管理和迭代管理。

## 本地预览

```bash
python3 -m http.server 4173
```

打开：

```text
http://127.0.0.1:4173
```

## 演示账号

```text
账号：admin
密码：admin
```

`auth-config.js` 的 `mode: "local"` 仅用于本机演示：上述账号与本机创建的成员账号不支持跨设备，也不是安全边界。生产环境设置 `mode: "cloud"` 并填写共享账号服务的 HTTPS 地址，不再接受 `admin/admin` 或本机登录标记。

## 共享账号服务

`auth-service/` 是 Cloudflare Workers + D1 账号服务。GitHub Pages 保留原页面地址，账号创建、登录、启停、删除和会话校验请求账号服务；原型内容与工具素材不会随账号自动同步。页面本身和公开仓库仍可访问，不能把前端登录视为私密文件托管。

已配置的生产账号服务：`https://orbit-workbench-auth.jp990916.workers.dev`。生产环境无公开的默认管理员密码，必须由所有者通过一次性初始化入口设置。

首次部署：复制 `auth-service/wrangler.example.jsonc` 为被忽略的 `auth-service/wrangler.jsonc`，创建 D1 数据库并填写真实绑定 ID。配置 `ALLOWED_ORIGINS` 为页面的精确来源，不使用通配符。通过 Wrangler secret 设置随机 `PASSWORD_PEPPER` 和一次性的随机 `SETUP_TOKEN`，不要将它们写入源码、前端或命令行参数。

```bash
pnpm exec wrangler login
pnpm exec wrangler d1 create orbit-workbench-accounts --location apac
pnpm exec wrangler d1 migrations apply DB --remote --config auth-service/wrangler.jsonc
pnpm exec wrangler deploy --config auth-service/wrangler.jsonc
pnpm exec wrangler secret bulk --config auth-service/wrangler.jsonc
```

最后一条命令从标准输入读取机密 JSON。保存部署返回的真实服务地址到 `auth-config.js`，启用云端模式并发布页面。使用只交给站点所有者的 `#setup=<SETUP_TOKEN>` 初始化入口，由所有者设置至少 12 位的管理员密码。页面读取后立即从地址栏清除初始化令牌，服务端通过唯一管理员账号防止重复初始化；完成后删除云端 `SETUP_TOKEN` secret。不要把初始化链接发给其他人。

新密码在浏览器用原生 PBKDF2-HMAC-SHA256、随机 128 位盐、600,000 次迭代计算摘要，服务端用独立 secret 做 HMAC-SHA256 后加密钥保护存储；仅通过 HTTPS 发送密码等价摘要，它仍应视为敏感凭据，不记录或公开。客户端计算不能代替服务端鉴权。云端接口逐一检查随机会话令牌及管理员权限，数据库仅保存令牌的 SHA-256 摘要。会话不勾选记住登录时最长 8 小时，勾选时 7 天；启停、删除和退出会撤销相应会话。登录和初始化有服务端限流，失败或离线时不会回退到本机演示账号。密码 pepper 必须保密并保留，直接轮换它会导致现有密码不可验证。

原浏览器中的管理员可通过「管理设置 → 迁移本机旧账号」上传原盐及 120,000 次迭代摘要，保持旧密码可用。迁移只新增，永不覆盖同名云端账号；完整成功后移除本机旧账号副本。旧账号保留较低的历史迭代次数，建议用强密码重新创建。自动化测试使用两份完全隔离的浏览器存储验证跨设备效果，以及迁移、撤销、权限、错误和不降级行为。

`auth-gateway/` 提供 Cloudflare Pages 备用入口，通过服务绑定转发至同一个账号 Worker，不复制账号或密钥。客户端通过不携带凭据的健康检查选择可连接入口，连接失败后在下次操作时重新检测；创建、修改、删除账号不会自动重发。部署说明见该目录的 README。默认域名的可达性仍取决于成员所在网络，不能保证所有网络都能访问；两个入口均不可达时需要进一步排查或接入自有域名。

参考：[Cloudflare D1](https://developers.cloudflare.com/d1/get-started/)、[OWASP 密码存储与 Pepper](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。

## 功能

- 管理员登录与退出
- 产品原型文档创建
- 新建原型文档本地持久化
- 产品文档列表
- 迭代看板
- 模块内搜索与空状态
- 工具箱：GIF 转 SVGA，支持拖拽选择、动画预览、尺寸和帧率设置、取消处理及下载
- 工具箱：移除图片背景，支持自动去除近似纯色背景、点选/套索/画笔修正及透明 PNG 导出
- 透明边缘优化：可选柔化锯齿、去白边并柔化，黑/白/棋盘格底色，以及导出文件首帧、中间帧、末帧预览

## 工具箱

登录后点击左侧「工具箱」，选择 GIF 并点击「开始转换」，完成后下载 `.svga` 文件。
所有素材在浏览器本地处理，不上传服务器；离开工具箱会释放当前文件和转换任务。

「移除图片背景」支持 PNG、JPG、WebP（20 MB、最长边 2048 px）。上传后自动去除与图片边缘连通的相近颜色背景。可调整颜色容差后重试，或使用相近颜色点选、套索选区、擦除/恢复画笔；支持撤销、恢复原图和下载透明 PNG。自动处理基于颜色连通性，不是 AI 人像分割；复杂纹理和与主体颜色相近的背景需要手动修正。

GIF 动画支持逐帧移除背景并重新导出透明 GIF，保留源动画帧延迟与循环参数；支持最多 300 帧、30 秒。GIF 只有一位透明度，因此动画边缘不支持 PNG 那样的半透明过渡，复杂帧建议拆帧精修。

图片上传后还可使用「智能指令 · 本地识别」：例如输入“去掉白色背景，然后擦除左侧 40%”或“恢复左侧 20%”。工具会拆成步骤、标出预计选区和覆盖比例，确认后一次执行并支持撤销。支持颜色、方位、面积百分比与移除/恢复意图；不使用云端 AI、API 密钥或额外 token。仅凭“去掉人物/某个物体”无法可靠定位时会拒绝执行，需改用颜色与位置描述或手动套索。

用途默认「表情包」：固定 SVGA 2.0、20 FPS、240 × 240 px，无需选择版本。
支持连续选择 1 至 30 次重复播放，源动画按原时长与帧节奏重采样后连续复制；最终时长为单次重采样时长乘以重复次数。素材等比居中，不放大小图，透明补边至正方形，不拉伸或裁切。
「通用素材」保留自定义尺寸、帧率及原动画时长。两种用途均固定输出 SVGA 2.0。

- 输出为 SVGA 2.0 逐帧位图动画，可能比原 GIF 更大，不是矢量化转换。
- 保留透明区域，处理 GIF 局部帧和 disposal 1/2/3；实色背景不会自动移除。
- 通用素材输出帧率可选 15/20/30/60 FPS，通过累计时长采样，时长误差不超过一帧；极短源帧可能合并。表情包固定重采样为 20 帧、1 秒。
- GIF 未指定时长或小于 20 ms 的帧统一按 100 ms 处理。循环次数交由 SVGA 播放器控制。
- 输入限制：20 MB、2048 × 2048 px、300 帧、30 秒；累计画布像素还受内存限制。
- 转换需要支持 Worker 和 OffscreenCanvas 的现代浏览器，建议使用新版 Chrome / Edge。

遇到透明轮廓上的浅色毛边，可在「透明边缘处理」选择「去白边并柔化」，转换后切换黑白底检查结果。
去白边在缩放后的最终尺寸执行，可选 1/1.5/2 px 去边宽度（默认 1.5），先收缩透明遮罩去除残留白色碎点，再以预乘颜色重建半透明轮廓；不再使用易漏检的白底混色估计。内部不透明像素的颜色保持原样，对窄的有色笔画做保留处理。
去边会略微收缩轮廓；细小装饰或白色细线可能受影响，可降低宽度或改选柔化锯齿。默认保留原始边缘，不自动处理无透明背景的素材。
结果预览直接使用导出 SVGA 中的 PNG 帧，不会把预览底色写入文件。原图若为实色背景，需要先完成抠图；此功能不自动去除黑底或白底。

## 开发与验证

### 设计文件互转

「工具箱 → 设计文件互转」可以直接选择 `.xd`、`.sketch`、`.fig` 文件，在浏览器 Worker 内解析、映射图层并下载另两种格式，无需第三方 Figma 插件、转换服务或 API 密钥。所有代码与依赖随站点发布，文件不上传。

当前为测试版，支持静态画板、分组、基础形状、贝塞尔路径、文字、基础填充、描边、阴影和图片。XD 导出使用原生透明度、线性渐变、阴影与布尔图形结构；多重填充、描边、填充透明度和混合模式拆为可编辑子图层，不再只取最后一个填充。保留独立圆角、隐藏图层及内部资源页；XD 不支持多页，页面按区域排放。

默认开启「阻止已知属性丢失」。发现图片裁剪、蒙版、嵌套裁切、混排文字、自动布局或其他未实现的等价映射时停止生成，并给出原因和示例图层；导出器也会检查源图层是否遗漏。关闭检查后可按兼容模式导出，但不能称为无损结果。检查通过也不是跨软件外观完全一致的保证，字体、布局和复杂效果仍需在目标软件中复核。组件状态、原型交互和变量关联等跨格式属性仍未完整支持。

不再设置原文件大小上限，大文件处理取决于浏览器和电脑可用内存。仍保留解压内容 400 MB、50,000 个图层的安全保护。目标软件需要安装原文件使用的字体。先保留原稿，再检查导出的文件。测试覆盖六个转换方向、原生格式字段、透明度与隐藏效果、多重绘制属性、内部资源页、保留检查拦截与兼容重试、超过 100 MB 文件的浏览器实际转换与下载及错误恢复；本机安装 Sketch 时还会使用原生工具验证生成的 `.sketch`。所有回归样例均为合成图形，不包含用户设计稿。

转换器内置 `toSorted`、`toReversed` 的兼容实现，支持缺少这些数组接口的浏览器，不改写已有原生实现。回归测试会在转换 Worker 中移除两个原生接口，验证 Figma 文件仍能读取并下载 XD / Sketch 结果。

格式适配代码位于 `src/design/`。Figma 二进制读写使用内嵌的 MIT 开源 [OpenPencil](https://github.com/open-pencil/open-pencil) 编解码库，Sketch 与 XD 的图层和文件结构适配由本项目实现；压缩使用 `fflate`，路径规范化使用 `svgpath`。许可证随构建写入 `assets/THIRD_PARTY_LICENSES.txt`。

```bash
pnpm install
pnpm build
pnpm test
```

测试需要安装 Chrome，覆盖真实浏览器上传与下载、背景去除和手动选区、官方 SVGA 播放器解析、透明度、局部帧合成、帧时长、缩放、错误处理、取消与离开清理。
`src/` 是工具源码，`assets/` 是构建产物和第三方许可证，需随源码提交以供 GitHub Pages 直接发布。
GitHub Pages 从 `main` 分支根目录部署，不需要线上安装依赖。

格式参考：[SVGA 官方协议](https://github.com/svga/SVGA-Format/blob/master/proto/svga.proto)。
GIF 解析使用 [gifuct-js](https://github.com/matt-way/gifuct-js)，兼容性测试使用 [SVGAPlayer-Web](https://github.com/svga/SVGAPlayer-Web)。
